USAGE
-----
First time:         ./setup.sh
Daily use:          ./start.sh (7B) or ./start.sh --fast (3B)
Ralph Loop:         ./ralph-loop.sh "task description"
Configure OpenCode: ./configure-opencode.sh --optimized
Verify system:      ./verify.sh
Health checks:      ./test.sh
Benchmark:          ./benchmark.sh
Get help:           ./start.sh --help

For OpenCode:
  Run: ./configure-opencode.sh --optimized
  This auto-configures ~/.config/opencode/config.json
  Model: claude-coder-fake (7B) or claude-coder-fast (3B)
  API:   http://localhost:4000
